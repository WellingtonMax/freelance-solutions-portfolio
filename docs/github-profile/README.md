### Current focus

I'm developing demonstrable solutions for **data cleanup, reporting automation, API integration, internal dashboards, and business workflow prototypes**. I value narrowly defined scopes, inspectable deliverables, and clear explanations of what is implemented versus what remains experimental.

### How I approach projects

`Problem → scope → implementation → verification → documentation → review`

I use AI-assisted development where appropriate and review the results. A working demonstration is not the same as a production deployment; security, testing, data ownership, and ongoing maintenance deserve their own explicit treatment.
