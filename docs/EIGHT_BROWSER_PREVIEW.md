# Eight-project local browser preview (unmerged PR snapshots)

This tool assembles **existing** browser interfaces from open pull requests into one local, clickable showcase. It does **not** create eight new products, merge code, publish a site, or prove that any PR passed its tests. All project samples are fictional. Do not enter customer records, credentials, or secrets.

## Build locally

From a cloned `WellingtonMax/freelance-solutions-portfolio` repository, with Python 3.11+ and Git available:

```sh
python tools/build_eight_preview.py --fetch
python -m http.server 8000 --bind 127.0.0.1 --directory preview-eight
```

Visit `http://127.0.0.1:8000`. Only public GitHub PR refs are fetched; **no files are uploaded**. To build entirely offline after fetching once, omit `--fetch`. The builder refuses to overwrite an existing `preview-eight/`; select an unused `--output` directory for another snapshot (then point `--directory` at it).

**Important security boundary:** this is a local **review of unmerged code**. The builder executes the existing `06-document-factory/factory.py` from PR #11 on a fixed fictional JSON sample to produce a real HTML quotation. Inspect the fetched source first; run in a disposable local environment, not alongside credentials or sensitive business data. Other browser demos run locally from their proposed JavaScript and should likewise be reviewed before use. If any fetch or build step fails, do not present the partial output as a complete preview.

## Check the builder

```sh
python -m unittest discover -s tests -p 'test_eight_preview.py' -v
```

This tests the builder's fixed source manifest, HTML links, honest status labels, generated-file checks and overwrite refusal using synthetic fixtures. It does **not** test every original application, a browser or GitHub CI.

## Integration sequence

The backend/integration owner must first resolve #11 against `main`, then validate and merge dependent frontend PRs in dependency order. The frontend and design teams review the actual interfaces. After eight stable browser entries are integrated and their tests verified, replace the snapshot builder with ordinary relative links from the primary showcase. **No public deployment is authorized by this preview tool.**
